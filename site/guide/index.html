Move your BaseCamp library to GPX

This guide takes you from a BaseCamp library on your Mac to GPX files in the same folders, and then into the apps you use.

1. Before you start

  • Use the Mac that holds your BaseCamp library, with a current version of Safari, Chrome or Firefox.
  • BaseCamp doesn’t need to open. Foldertrail reads the library files themselves.
  • Foldertrail only reads your library. It never changes it, and it never uploads it.

Don’t delete your library

If BaseCamp stops opening after a macOS update, your library is still on your Mac. Keep it: it’s what Foldertrail reads.

2. Make a safety copy

Before you do anything else, keep a copy of your library somewhere safe, such as an external drive.

If BaseCamp still opens

  1. In BaseCamp, choose File › Backup.
  2. Save the backup file. It ends in .Backup.

BaseCamp’s manual says a backup holds all your data, lists and folders in one file. You can drop that file straight into Foldertrail.

If BaseCamp no longer opens

  1. Find your library folder (step 3 shows where).
  2. In Finder, copy the whole Database folder to an external drive or another folder, with BaseCamp closed.

3. Find your library

BaseCamp for Mac keeps its library in a folder inside your user Library:

  1. In Finder, choose Go › Go to Folder, or press ⌘⇧G.
  2. Type or paste this path, then press Return: ~/Library/Application Support/Garmin/BaseCamp/Database
  3. Inside are one or more folders named with a version number, such as 4.8. The one with the highest number is your current library.

Finder hides your Library folder, but Go to Folder still opens it.

If you moved your library

A library you created yourself is a package that ends in .bclibrary. While BaseCamp still opens, BaseCamp › Preferences › Advanced › Library shows where it is. You can drag the package into Foldertrail as it is.

4. Open it in Foldertrail

  1. Open the converter in Safari, Chrome or Firefox.
  2. Drag the version folder (such as 4.8) or your .Backup file onto the page. You can also use Choose folder or Choose backup file.
  3. Wait while it reads. A large library can take a minute or two.

Chrome says “Upload”

If you choose a folder in Chrome, it asks “Upload N files to this site?”. That is Chrome’s wording for letting the page read the files. They stay on your Mac.

5. Check the preview

The preview is free. It shows:

  • every folder and list, with how many waypoints, tracks and routes each holds;
  • what won’t convert, and why;
  • notes from reading, such as track details that couldn’t be read.

If something looks wrong, the page offers a diagnostic report. It describes only the structure of the library files (sizes, counts and version numbers) and holds no names, notes, places, coordinates, times or file paths. Foldertrail never sends it: you copy it and decide whether to share it.

6. What’s in the download

One ZIP file named like Foldertrail export 2026-10-06.zip, with the date you made it. Double-click it in Finder to unzip it. Inside:

GPX/My Collection/…/<list>.gpx
One GPX file for each list, inside folders named like yours.
GPX/All items.gpx
Everything that converted, in one file.
GPX/Not in any list.gpx
Items that were in no list, if there are any.
GPX/_Duplicate names/
Items whose list couldn’t be decided because another item of the same kind has the same name, if there are any. Foldertrail doesn’t guess: the report names the lists that refer to them.
KML/My Collection.kml
Your whole tree in one file, if you chose the KML option.
report.html, report.txt
What converted, what didn’t, and why.
READ-ME-FIRST.txt
A short note on what each file is.

An item that was in several lists is in each of those lists’ files. To avoid copies, import one list at a time, or All items.gpx once.

If you choose “One GPX file per item” before downloading, each list becomes a folder holding one GPX file per waypoint, track or route.

7. Load the files into other apps

GPX files hold waypoints, tracks and routes, but no folders. The folders are the ones on your Mac, so each app below shows your data in its own way. Steps are taken from each maker’s help pages, listed under Sources. Apps change, so check their current help if a step doesn’t match.

Garmin Explore

Garmin’s own manuals describe this route for BaseCamp data: export it, then import it on the Explore website. On explore.garmin.com, open the map, click Import, and follow the steps to add the files to a collection. Explore accepts GPX, KML and KMZ files.

Garmin’s help doesn’t describe collections inside collections, so your deeper folder levels won’t carry over. Importing one list’s GPX file at a time, into a collection with the same name, keeps things easy to find. Then sync your device as its manual describes.

A Garmin device, over USB

Garmin’s manuals describe copying files to a device over USB, and the steps differ by model. Two examples:

  • The Tread manual says to copy GPX files into the GPX folder on the device, and that a Mac may need extra software, such as Android File Transfer, to read and write files on it.
  • The GPSMAP 67 manual says macOS doesn’t detect that device by default, and that you must use Garmin Express to work with files on it.

Look up “Transferring files” in your own device’s manual.

Garmin Connect

We couldn’t find Garmin’s own instructions for importing a GPX file into Garmin Connect, so this guide doesn’t give steps for it.

Not checked by us: Garmin forum users describe importing a GPX file as a course from the Courses page of the Connect website.

Gaia GPS

On gaiagps.com/map, click Import Data on the right-hand toolbar, or drag files onto the map, then click Save Item. Gaia puts each imported file in its own folder, named after the file, so importing list by list gives you one folder per list. Gaia accepts up to 1,000 features, such as waypoints and tracks, per file.

CalTopo

Click Import at the top of the Map Objects side bar and choose a file. CalTopo accepts GPX and KML, but it sorts what it imports into its own folders: markers in one, lines in another. Your folders aren’t kept there. CalTopo keeps folders only from GeoJSON files, which Foldertrail doesn’t write yet.

Google Earth

Use the KML file: it holds your whole folder tree. In Google Earth on the web, click Open local KML editor on the home screen, then Open KML from device, and choose the file. To add it to a Google Earth project instead, choose Import file to project, then Upload from device. Projects are kept in your Google Drive, and one import holds up to 10,000 features.

Other apps

Most map apps import GPX files. Look for Import or Open in the app.
