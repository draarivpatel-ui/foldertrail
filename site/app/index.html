    Where is my library?

    If BaseCamp no longer opens

    1. In Finder, press ⌘⇧G (Go to Folder) and paste this path: ~/Library/Application Support/Garmin/BaseCamp/Database
    2. Drag the folder with the highest version number, such as 4.8, onto this page.

    If BaseCamp still opens

    1. In BaseCamp, choose File › Backup and save the backup file.
    2. Drop the .Backup file here, or use Choose backup file.

    A backup is a single file that holds the whole library.

    Keep your library somewhere else, in a .bclibrary package? Drag the package here.
